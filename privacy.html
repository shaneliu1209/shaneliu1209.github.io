SITE INFORMATION

Privacy

Last updated · October 8, 2026

This is a personal showcase of ideas and visual experiments. This notice explains its website features, browser storage and hosting.

Website features

There are no sign-up forms, contact forms, accounts or checkout. Videos, images and fonts are served with the website. The website code does not set cookies or load advertising pixels, third-party analytics scripts or social-media embeds.

Hosting

The website is hosted on GitHub Pages. GitHub states that it logs and stores visitors’ IP addresses for security purposes, whether or not they are signed in to GitHub. Its handling of that information is described in the GitHub Privacy Statement. No separate visitor-tracking service is added by this website.

Motion preferences

Turning on “Reduce motion” saves that choice in this browser’s local storage. The website code does not transmit it. Turn the option off or clear this site’s browser data to remove it. The page also respects the device’s reduced-motion setting.

External links

Following an external link takes you to a different website, where its own privacy practices apply. External content is not embedded in this site.

Changes

This notice will be updated if the website’s features or data-handling practices change. The date above identifies the latest version.
